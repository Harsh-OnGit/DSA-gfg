<h2><a href="https://www.geeksforgeeks.org/problems/min-cost-to-make-size-1/1">Min Cost to Make Size 1</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p style="text-align: justify;"><span style="font-size: 14pt;">Given an array, <strong>arr[]</strong>, you need find the minimum cost to reduce array size to one. You are allowed to select a pair of elements and remove the larger one of these two. Cost of this operation is equal to value of smaller one. </span></p><p><span style="font-size: 14pt;"><strong>Examples</strong>:&nbsp;</span></p><pre><span style="font-size: 14pt;"><strong>Input</strong>: arr[] = [4, 3, 2]<br><strong>Output</strong>: 4<br><strong>Explanation</strong>: Choose (4, 2) so 4 is removed, new array = [2, 3]. Now choose (2, 3) so 3 is removed. So total cost = 2 + 2 = 4</span></pre><pre><span style="font-size: 14pt;"><strong>Input</strong>: arr[] = [3, 4]<br><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;"><strong>Output</strong>: 3<br></span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;"><strong>Explanation</strong>: Choose 3, 4, so cost is 3. </span></span></pre><pre><span style="font-size: 14pt;"><strong>Input</strong>: arr[] = [1]</span><br><span style="font-size: 14pt;"><strong>Output</strong>: 0</span><br><span style="font-size: 14pt;"><strong>Explanation</strong>: The array is already of size one, so no operations are needed.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Greedy</code>&nbsp;
